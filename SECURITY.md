# Xavfsizlik / Security

- Ma'lumotlar foydalanuvchi qurilmasida (brauzer yoki Daftar papkasi) saqlanadi; ushbu omborda foydalanuvchi ma'lumoti yo'q.
- Omborga **kalitlar, parollar, bot tokenlari, shaxsiy kalitlar va shaxsiy ma'lumot qo'shmang.**
- Xavfsizlik muammosini ochiq Issue sifatida emas, muallifga shaxsiy xabar orqali yuboring.
